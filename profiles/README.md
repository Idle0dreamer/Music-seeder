# Profiles

This directory is reserved for provenance-bearing tradition, region, school,
repertoire, and performer profiles. It contains no authentic regional profile
yet.

A profile is admissible only when its sources, derivation, rights basis,
attribution, and known community or repertoire conditions are recorded.
CC BY-SA 4.0 covers only original profile expression that the contributor has
the right to license; it does not erase restrictions on source material or
claim ownership of musical facts and principles.

See `LICENSE_POLICY.md` and `ATTRIBUTION.md`.
