# Nahawand canonical package

This package implements the canonical Arabic repertoire boundary for Maqam
Nahawand. The source description identifies Nahawand as the principal maqām of
its family: root Jins Nahawand on the tonic, followed by either Jins Hijaz or
Jins Kurd on the fifth degree.

Source records:

- [Maqam Nahawand](https://www.maqamworld.com/en/maqam/nahawand.php)
- [Jins Nahawand](https://maqamworld.com/en/jins/nahawand.php)
- [Jins Hijaz](https://maqamworld.com/en/jins/hijaz.php)
- [Jins Kurd](https://maqamworld.com/en/jins/kurd.php)

The implementation keeps the root and upper-jins alternatives as separate
typed branches. Their paths, obligations, phrase cells, contextual ratio
targets and provenance travel through the shared family seam; timing arrives
from the explicit external performance profile;
the branch identities are not aliases or scale-array substitutions.

This is a canonical repertoire package, not a claim about every regional,
historical, performer, or school realization. Those variants require separate
profile identities and evidence.
