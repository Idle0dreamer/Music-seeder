# Bayati case study specification

This is a test harness for an Egyptian/Levantine urban Arabic Bayati taqsim
profile. It is not yet profile data and is not evidence that other regional
Bayati practices behave identically.

## Required root-jins description

The profile must supply:

- tonic role and ghammaz candidates;
- characteristic register and register-dependent variants;
- emphasis and attraction roles;
- baggage tones outside the narrow jins span;
- entry, establishment, departure, and return cells;
- cadence families and closure strengths;
- contextual intonation trajectories;
- performer and repertoire variants.

No interval array is accepted as a substitute.

## Candidate internal network

Pedagogical sources describe a network involving Bayati, Rast, Nahawand, Hijaz,
and Ajam at particular tonal roles. The profile data must state:

- exact node role and register;
- permitted tonicization level;
- approach and pivot family;
- minimum evidence and residence;
- phrase-stage condition;
- legal return path;
- negative or unsupported direct edges;
- source and confidence.

The presence of compatible tones is not sufficient to create an edge.

## Minimum phrase tests

1. Establish root Bayati without a foreign-center claim.
2. Introduce a brief color and return without mislabeling it as modulation.
3. Establish one internal jins using motif and cadence evidence.
4. Reject a plausible pitch-set transition whose graph path is unsupported.
5. Reach a prepared register/climax state and return idiomatically.
6. Repeat and vary a motif while preserving identity.
7. Produce question–response relations with distinct boundary strengths.
8. Conclude through root-jins re-establishment and a final cadence.

## Minimum intonation tests

For important pitch roles, compare contextual distributions across:

- ascent and descent;
- stable emphasis and connective motion;
- root-jins establishment and internal tonicization;
- cadence approach;
- neighboring roles;
- performer and local profile.

The expected result is conditional variation, not one “Bayati scale.”

## Completion condition

This case becomes generative only after:

- a rights-cleared, profile-matched corpus exists;
- at least two qualified annotators review structural layers;
- the graph contains sourced positive and negative constraints;
- motif, cadence, and intonation coverage meets declared thresholds;
- validation gates G0–G7 pass.
