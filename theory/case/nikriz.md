# Nikriz canonical package

The canonical Nikriz package follows the published family description: root
Jins Nikriz on the tonic, followed by Jins Nahawand on the fifth degree.

Source: [Maqam Nikriz](https://www.maqamworld.com/en/maqam/nikriz.php).

The upper-jins path is represented as a typed branch with its own provenance,
not as a scale alias.
